# AutoQuest Engineering — démarrer

Cette version remplace les petites leçons par **180 séances de formation
avec mini-cours, exemples résolus, calculs, dossiers E-City et examens**.

## Essayer le site maintenant

1. Extrais **tout** le ZIP.
2. Ouvre le dossier `AutoQuest`.
3. Sous Windows : double-clique sur **DEMARRER_WINDOWS.bat**.
4. Sur Mac/Linux : exécute `sh START_MAC_LINUX.sh`.
5. Le navigateur ouvre **http://localhost:3000/**. Garde le terminal ouvert.

Python 3 doit être installé pour ce lancement local. Node.js n’est pas nécessaire
pour essayer la version déjà compilée. **N’ouvre pas `index.html` directement.**

Sur téléphone : même Wi-Fi que le PC, puis adresse réseau affichée dans le
terminal. Après publication, chaque visiteur ouvre simplement le lien du site.

## Comment travailler une journée

- **Cours** : rappel actif, explication et chapitre appliqué avec tableaux,
  photos ou schémas, puis modèle et limites.
- **Exemple résolu** : données, conversions, étapes, interprétation.
- **Entraînement** : socle, trois calculs sur un autre jeu de valeurs et revue technique.
- **Dossier E-City** : troisième calcul, sensibilité, trois options, décision,
  risque et trois preuves proposées. Export Markdown pour ton dépôt GitHub.
- **Bilan** : explication orale et passage à la journée suivante.

Prévois **35 min environ, au moins 20 min de travail actif** ; un dossier plus
complet peut demander 45 min ou davantage. La durée est une estimation, sans
minuterie qui bloque artificiellement la navigation.

## Examens

À chaque module : **12 questions**, deux sujets alternés, **80 % requis**
(au moins 10/12), corrigé après remise. L’examen blanc est disponible librement.
La validation demande de réussir les entraînements de toutes les leçons du
module. Les examens ne donnent pas de XP. Les dossiers rédigés restent à relire.

## Comptes et publication

La démo garde la progression dans ce navigateur. Pour retrouver le même compte,
les notes, XP et dossiers sur plusieurs appareils, configure **Supabase** et
publie avec **Vercel**, selon **README_FR.md**. Le code et les quatre fichiers
SQL sont inclus ; aucun compte externe n’a été configuré à ta place.

Les cours principaux et exercices sont FR/EN. Les 70 chapitres appliqués issus
du cours détaillé sont conservés en français et clairement signalés en anglais.
Il s’agit d’une formation pédagogique, sans diplôme ni certification véhicule.
